# A_Dream_of_Red_Mansions
本项目系红学入门最佳读本——《潼溪注脂砚斋重评石头记》。

书中注释来源有考证派和索隐派红学家的观点的汇集，有传统红学家在红楼梦的版本学和探佚研究上的成果归纳，也有时下读者对红楼梦的个人解读，有对成书时代文化习俗和社会背景的考证，也有对书中人物行为动机及人物性格特点的分析，对书中部分诗词也进行了评析。对众说纷纭的红学问题的各种观点收集比较齐全，例如爬灰问题，作者与曹寅家族的关系问题等，对相关资料和观点进行了比较完整的整理。

提供`PDF`版和`EPUB`版两个版本的最终成书，保存在`output`目录下。两个版本的脂批均采用双行夹批形式显示。直接在浏览器中阅读HTML版本效果更佳，如果直接用浏览器的`file://`协议阅读`HTML`文件出现异常（本人测试过程中无异常），可以尝试开启本地`HTML`服务器后阅读。一种简单的开启方法是先安装`Python`，然后在项目的根目录下执行如下命令(其中的`port`为可选的端口号)：

```bash
python -m http.server [port]
```



`PDF`版注释采用脚注排版，导航功能十分完善：点击目录可以跳转到对应回目的正文，点击回目正文的标题可以返回对应的目录项。每页均有页眉，可以看出目前阅读的内容是哪一回的，点击页眉也可以回到目录中对应的回目。

`EPUB`版注释采用尾注形式排版，点击注释引用会在视口中央显示注释内容。注释引用与注释内容是交叉链接。`EPUB`版有完整目录，提供了查拼音功能，遇到读音吃不准的字，可以选择它，然后点击任意位置使阅读器自带的控件隐藏后点击拼音按钮即可显示刚选择的文字的拼音。为了排版美观，`EPUB`版内嵌字体文件补充了字符集中不存在的文字，没有使用图片字符，因此建议不要更换字体，以免有少量字符不能正常显示。`EPUB`版推荐使用`Calibre`阅读器阅读，以充分发挥书中`JavaScript`的功能，不支持`JavaScript`的阅读器或者对`JavaScript`支持与浏览器标准相差太大的阅读器，脂批双行夹批显示、注释内容提示框弹出显示而不是跳转以及拼音功能可能无法正常使用，但阅读文字不受影响。
